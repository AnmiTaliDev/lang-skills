# agnostic-lang

Agent skill for writing, editing, reviewing, and explaining code in
[Agnostic](https://github.com/agnosticlang/agnostic).

## Contents

- `SKILL.md`: entry point with the minimal program, common mistakes, and workflow.
- `references/syntax.md`: language syntax and semantics.
- `references/stdlib.md`: standard library.
- `references/cli.md`: compiler flags, memory modes, targets, and build.

## Installing

```bash
npx skills add AnmiTaliDev/lang-skills --skill agnostic-lang
```

Or copy this folder into the agent's skills directory (for example
`.claude/skills/`).
